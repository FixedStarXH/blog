关于本系统

这是一个多作者博客系统:注册用户即可投稿,编辑与管理员审核后发布,支持文章、专栏、分类、标签、评论的完整内容生态。

系统基于 Go 与 Gin 构建,后端分层架构,前端为瑞士国际主义风格的 SPA 应用。

技术栈

后端 Go / Gin / GORM / MySQL,前端原生 HTML / CSS / JS(SPA)。工程化覆盖分层架构、JWT 鉴权、RBAC 权限、投稿审核工作流、文件上传、IP 防刷、定时发布、软删除等实践。

核心能力

  • 多作者投稿审核工作流
  • 三级角色权限(用户/编辑/管理员)
  • 专栏与内容组织
  • 完整后台管理控制台
◎

角色权限

  • 普通用户 投稿·评论
  • 编辑 审核·管理
  • 管理员 全权·设置
