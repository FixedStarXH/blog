# 博客系统 — 接口设计(多用户 CMS)

> 技术栈:Gin + JSON
> 基础路径:`/api`
> 文档版本:v2.0
> 更新日期:2026-08-01

---

## 1. 通用约定

### 1.1 统一响应结构

```json
{ "code": 200, "message": "success", "data": {} }
```

### 1.2 状态码

| code | 含义 |
|------|------|
| 200 | 成功 |
| 400 | 参数错误 / 业务失败 |
| 401 | 未登录 / 未授权 |
| 403 | 无权限(RBAC 校验失败) |
| 404 | 资源不存在 |
| 500 | 服务器错误 |

> HTTP 状态码与业务 code 分离。前端**优先判断业务 code**。

### 1.3 鉴权方式(JWT + RBAC)

- 登录/注册后签发 `{ "token": "<JWT>", "user": {...} }`。
- 受保护接口需 `Authorization: Bearer <token>`。
- JWT 载荷:`{ "user_id": 1, "role": 1, "exp": ... }`。
- **角色**:0 游客 / 1 普通用户 / 2 编辑 / 3 管理员。
- 游客(0)为未登录状态,**不存数据库**;`users.role` 仅存 1/2/3。
- 中间件按接口要求校验 `role >= N`,不足返回 `code 403`。

### 1.4 文章状态机

| status | 含义 |
|--------|------|
| 0 | 草稿(仅作者可见) |
| 1 | 已发布(前台可见) |
| 2 | 待审核(投稿后) |
| 3 | 已驳回(作者可修改重提) |

### 1.5 评论状态机

| status | 含义 |
|--------|------|
| 0 | 待审(发表后默认,后台可见) |
| 1 | 已通过(前台展示) |
| 2 | 已驳回(后台可见) |

## 2. 公共接口(无需登录)

### 2.1 文章列表

```
GET /api/articles?page=1&pageSize=10&categoryId=&tag=&keyword=&authorId=&sort=latest|hot
```

- 只返回 `status=1`(已发布)文章。
- 支持按作者 `authorId` 筛选(作者页用)。

响应(不含 Content):

```json
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1, "title": "…", "summary": "…", "coverImage": "",
        "viewCount": 128, "likeCount": 12,
        "createdAt": "2026-07-30T15:00:00+08:00",
        "author": { "id": 1, "nickname": "Lumi", "avatar": "", "role": 2 },
        "category": { "id": 2, "name": "Go后端" },
        "tags": [ { "id": 1, "name": "gin" } ]
      }
    ],
    "total": 32, "page": 1, "pageSize": 10
  }
}
```

### 2.2 文章详情

```
GET /api/articles/:id
```

- 返回正文 + 作者 + 分类 + 标签 + 上一篇/下一篇 + 相关推荐。
- 私密/待审核文章按权限返回。
- **私密文章**(`password` 非空):本接口**不返回** `content`,只返回 `hasPassword: true`,需先调用 2.2.1 解锁。

### 2.2.1 私密文章解锁(前端已实现)

```
POST /api/articles/:id/unlock
Content-Type: application/json
```

请求体:

```json
{ "password": "secret123" }
```

| 返回 | 说明 |
|------|------|
| 密码正确 | `{ "code":200, "data": { "content": "<p>全文…</p>" } }`,并返回 `unlocked: true` |
| 密码错误 | `code 400, message "密码错误"` |
| 文章不存在 | `code 400, message "文章不存在"` |
| 非私密文章 | `code 400, message "该文章无需密码"` |

> 前端行为:详情接口发现 `hasPassword` 时展示密码框,调用本接口成功后渲染正文,并将 `content` 缓存在 `sessionStorage`。

### 2.3 浏览量自增 / 点赞

```
PUT /api/articles/:id/view    → { "viewCount": 130 }
PUT /api/articles/:id/like    → { "likeCount": 13, "already": false }
```

### 2.4 分类 / 标签 / 归档 / 热门

```
GET /api/categories           → [{ id, name, description, articleCount }]
GET /api/categories/:id/articles   → 按分类查文章(等价 /api/articles?categoryId=:id)
GET /api/tags                 → [{ id, name, articleCount }]
GET /api/tags/:name/articles  → 按标签查文章(等价 /api/articles?tag=:name)
GET /api/archive              → [{ year, month, articles: [] }]
GET /api/articles/hot?limit=5 → 热门 TOP
```

> 前端统一用列表接口 `/api/articles` 的查询参数(`categoryId` / `tag`)做筛选;`:id/articles` 形式是等价别名,后端实现时二选一即可,推荐统一走 `/api/articles` 参数。

### 2.5 专栏

```
GET /api/columns              → [{ id, name, description, authorId, articleCount }]
GET /api/columns/:id          → 专栏详情
GET /api/columns/:id/articles → 该专栏文章
```

### 2.6 作者页

```
GET /api/authors/:id          → { user, articleCount, commentCount, articles: [] }
```

### 2.7 评论

```
GET  /api/articles/:id/comments   → 已通过评论(含回复)
POST /api/articles/:id/comments   → 发表评论(登录或游客昵称)
```

```json
// 已登录用户(自动取 user_id);顶层评论 parentId 为 null,回复填父评论 id
{ "content": "写得很棒", "parentId": null }
// 游客(需提供昵称,评论默认待审)
{ "content": "写得很棒", "nickname": "路人甲", "parentId": null }
```

> ⚠️ 顶层评论 `parentId` 必须传 **`null`**,不要用 `0`(数据库 `parent_id` 为可空指针,`0` 会破坏楼中楼结构)。前端 `article.js` 已按 `null` 实现。

### 2.8 站点信息 / 每日一言

```
GET /api/site      → { title, subtitle, description, logo, stats }
GET /api/quote/random
GET /api/links     → 启用中的友链
GET /rss.xml
GET /sitemap.xml
```

## 3. 用户接口

### 3.1 注册

```
POST /api/auth/register
```

```json
{ "username": "lumi", "email": "lumi@example.com", "password": "123456" }
```

| 字段 | 规则 |
|------|------|
| username | 必填,3-20 字,唯一 |
| email | 必填,合法邮箱,唯一 |
| password | 必填,≥6 位 |

响应:`{ "token": "...", "user": { "id":1, "username":"lumi", "role":1 } }`(注册即登录)

### 3.2 登录

```
POST /api/auth/login
```

```json
{ "username": "lumi", "password": "123456" }
```

### 3.3 当前用户信息(需登录)

```
GET /api/auth/me   → { "id":1, "username":"lumi", "nickname":"", "avatar":"", "role":1, "email":"…" }
```

### 3.4 更新个人资料(需登录)

```
PUT /api/auth/me
```

```json
{ "nickname": "Lumi", "avatar": "/uploads/…" }
```

### 3.5 修改密码(需登录)

```
PUT /api/auth/password
```

```json
{ "oldPassword": "123456", "newPassword": "abc123" }
```

## 4. 我的投稿 / 作者中心(需登录)

### 4.1 我的文章

```
GET /api/my/articles?status=&page=
```

- 只返回当前登录用户的文章,含全部状态(草稿/待审/已发布/已驳回)。

### 4.2 投稿文章

```
POST /api/my/articles
```

- 与后台新建文章相同结构,默认 `status=2`(待审核),作者无发布权限。

### 4.3 编辑我的文章

```
PUT /api/my/articles/:id      → 草稿可直接改;待审核需重新提交;已发布需走修订
DELETE /api/my/articles/:id   → 删除自己的文章
```

### 4.4 查看驳回原因

```
GET /api/my/articles/:id      → 含 rejectReason(驳回原因)
```

### 4.5 我的专栏(需登录)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/my/columns` | 我的专栏列表 |
| POST | `/api/my/columns` | 创建专栏(专栏归属自己) |
| PUT | `/api/my/columns/:id` | 更新自己的专栏 |
| DELETE | `/api/my/columns/:id` | 删除自己的专栏 |

- 专栏是作者的"个人空间"(见数据库设计 3.5),**任何登录用户都可自建**;管理员在后台管理全部专栏。

## 5. 后台接口(管理控制台)

> 前缀 `/api/admin`,按接口标注所需 `role >= N`。

### 5.1 登录(管理员入口)

```
POST /api/admin/login
```

- 仅 `role >= 2`(编辑/管理员)可登录后台。
- 普通用户登录返回 `code 403 "无权限"`。

### 5.2 仪表盘(role>=2)

```
GET /api/admin/dashboard
```

`counts` 字段(前端 dashboard 实际读取):

```json
{
  "counts": {
    "articles": 86,           // 文章总数(已发布)
    "users": 45,              // 用户总数
    "pendingArticles": 5,     // 待审核文章数(状态=2)
    "pendingComments": 3,     // 待审核评论数(状态=0)
    "comments": 320,          // 评论总数(已通过)
    "views": 12400            // 总浏览量
  },
  "hotArticles": [...],       // 热门 TOP5(按 viewCount 降序)
  "pendingList": [ { "id":1, "title":"待审核文章", "author":"…", "createdAt":"…" } ],
  "recentComments": [...]
}
```

> ⚠️ 字段名以**前端为准**:`pendingComments`(待审核评论)必须返回;前端 `dashboard.html` 读取 `articles / views / comments / pendingComments`。

### 5.3 文章审核工作流(role>=2)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/articles?status=2&page=` | 按状态筛选(0草稿/1发布/2待审/3驳回) |
| GET | `/api/admin/articles/:id` | 详情(含作者、驳回原因) |
| PUT | `/api/admin/articles/:id/approve` | 审核通过 → 发布 |
| PUT | `/api/admin/articles/:id/reject` | 驳回,请求体 `{ "reason": "内容不符合规范" }` |
| PUT | `/api/admin/articles/:id` | 编辑已发布/待审文章 |
| DELETE | `/api/admin/articles/:id` | 删除(软删) |
| PUT | `/api/admin/articles/:id/top` | 置顶/取消 |

### 5.4 用户管理(role=3 管理员)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/users?page=&role=&status=` | 用户列表 |
| PUT | `/api/admin/users/:id/role` | 分配角色,`{ "role": 2 }` |
| PUT | `/api/admin/users/:id/status` | 禁用/启用 `{ "status": 0|1 }` |
| GET | `/api/admin/users/:id` | 用户详情(文章/评论数) |

### 5.5 分类 / 标签 / 专栏管理(role=3)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | `/api/admin/categories` | 分类列表/新建 |
| PUT/DELETE | `/api/admin/categories/:id` | 更新/删除(有文章禁删) |
| GET/POST | `/api/admin/tags` | 标签列表/新建 |
| PUT/DELETE | `/api/admin/tags/:id` | 更新/删除 |
| GET | `/api/admin/columns` | 全部专栏列表 |
| PUT/DELETE | `/api/admin/columns/:id` | 更新/关闭/删除(管理全部专栏) |

> 专栏的创建/编辑归作者自己(`/api/my/columns`,见 4.5);管理员在此管理全部专栏。

### 5.6 评论管理(role>=2)

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/admin/comments?status=0` | 按状态筛选 |
| PUT | `/api/admin/comments/:id/status` | 通过/驳回 |
| DELETE | `/api/admin/comments/:id` | 删除 |
| POST | `/api/admin/comments/batch` | 批量操作 |

### 5.7 图片图库(需登录)

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/admin/upload` | multipart 上传,≤5MB,jpg/png/gif/webp |
| GET | `/api/admin/images?page=` | 图片列表 |
| DELETE | `/api/admin/images/:id` | 删除 |

### 5.8 站点设置 / 友链 / 后台改密

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/PUT | `/api/admin/settings` | 站点设置(role=3) |
| GET/POST | `/api/admin/links` | 友链列表/新建(role=3) |
| PUT/DELETE | `/api/admin/links/:id` | 更新/删除(role=3) |
| PUT | `/api/admin/password` | 后台修改自己的登录密码(role>=2),请求体 `{ "oldPassword", "newPassword" }`,复用 §3.5 逻辑 |

> 前端 `settings.html` 的"修改密码"调用 `PUT /api/admin/password`。

## 7. 权限速查

| 接口组 | 游客 | 用户 | 编辑 | 管理员 |
|--------|:---:|:---:|:---:|:---:|
| 前台文章/评论/互动 | ✅ | ✅ | ✅ | ✅ |
| 评论/点赞 | ✅ | ✅ | ✅ | ✅ |
| /api/auth/* | 注册登录✅ | ✅ | ✅ | ✅ |
| /api/my/articles(投稿) | — | ✅ | ✅ | ✅ |
| /api/my/columns(自建专栏) | — | ✅ | ✅ | ✅ |
| /api/admin/*(审核/评论/图片/设置) | — | — | ✅ | ✅ |
| /api/admin/users(用户管理) | — | — | — | ✅ |
| /api/admin/categories|tags(分类/标签) | — | — | — | ✅ |
| /api/admin/columns(管理全部专栏) | — | — | — | ✅ |

> 说明:专栏**作者可自建**(`/api/my/columns`),管理员在后台(`/api/admin/columns`)管理**全部**专栏;权限表据此区分。
