# 博客系统 — 需求文档(多用户 CMS 型)

> 项目代号:blog-system
> 技术栈:Go + Gin + GORM + MySQL / 原生 HTML + CSS + JS(SPA)
> 架构:前后端分离,后端纯 API + 静态托管
> 文档版本:v2.0
> 更新日期:2026-08-01

---

## 1. 项目概述

### 1.1 项目定位

一套**面向多用户的通用博客系统(CMS)**,支持:

- **多作者**:注册用户可投稿,编辑/管理员审核后发布
- **多角色**:普通用户 / 编辑 / 管理员 三级权限
- **内容管理**:文章、专栏、分类、标签、评论的完整管理
- **开放平台**:注册登录、点赞、评论、订阅

> 与"个人博客"的区别:不再是单作者的单人日记,而是**内容平台化的系统**,强调用户体系、审核工作流、权限管理。

### 1.2 项目目标

| 目标 | 说明 |
|------|------|
| 内容平台 | 支持多作者投稿、审核、发布的内容生产流程 |
| 用户体系 | 注册、登录、角色权限、个人中心 |
| 完整后台 | 用户 / 文章 / 评论 / 内容的一站式管理 |
| 工程实践 | 分层架构、JWT、RBAC、工作流状态机等 Go Web 核心能力 |

## 2. 用户角色与权限(RBAC)

| 角色 | 权限等级 | 说明 |
|------|---------|------|
| 游客 | 0 | 浏览前台文章、评论(需注册或游客昵称) |
| 普通用户 | 1 | 注册登录;**投稿文章**(待审核)、发表评论、点赞、自建专栏 |
| 编辑 | 2 | 普通用户权限 + **审核文章**、管理评论、自建专栏 |
| 管理员 | 3 | 全部权限:用户管理、角色分配、全站文章/分类/标签/设置管理 |

**权限矩阵:**

| 操作 | 游客 | 普通用户 | 编辑 | 管理员 |
|------|:---:|:---:|:---:|:---:|
| 浏览文章 | ✅ | ✅ | ✅ | ✅ |
| 评论/点赞 | ✅ | ✅ | ✅ | ✅ |
| 投稿文章 | — | ✅ | ✅ | ✅ |
| 管理自己的文章 | — | ✅ | ✅ | ✅ |
| 审核文章 | — | — | ✅ | ✅ |
| 管理评论(删除/驳回) | — | — | ✅ | ✅ |
| 用户管理/角色分配 | — | — | — | ✅ |
| 分类/标签/站点设置 | — | — | — | ✅ |

| FR-1.6 | 每日一言 | 随机引言 |

### 3.2 文章 (Article)

| 编号 | 功能 | 说明 |
|------|------|------|
| FR-2.1 | 文章列表 | 按分类/标签/关键词/作者筛选,分页,排序(最新/最热) |
| FR-2.2 | 文章详情 | 正文、作者信息、阅读时长、TOC、上一篇/下一篇、相关推荐 |

## 5. 核心流程

### 5.1 投稿审核流程(系统核心)

```
作者登录 → 新建文章(状态=待审核)
              │
              ▼
     编辑/管理员 审核
        │            │
      通过          驳回
        │            │
        ▼            ▼
   发布(可见)    退回作者(附原因)
                   │
                   ▼
              作者修改后重新提交 → 再次审核
```

- 文章状态机:`草稿(0) → 待审核(2) → 已发布(1)` 或 `已驳回(3)`
- 作者只能看到/编辑自己的文章;编辑/管理员可见全部

### 5.2 注册→投稿→发布流程

```
游客注册 → 登录 → 个人中心 → 投稿文章 → 待审核 → 审核通过 → 前台展示
```
